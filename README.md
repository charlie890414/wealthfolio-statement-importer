# Wealthfolio 對帳單匯入

將富邦證券複委託、永豐證券、Charles Schwab、基富通與中信 ESPP 的 CSV 對帳單轉換為 Wealthfolio 活動，先預覽並驗證，再直接匯入或下載標準 CSV。

## 開發

```bash
pnpm install
pnpm type-check
pnpm test
pnpm build
pnpm dev:server
```

每次匯入只處理一個 CSV，並由使用者選擇目的帳戶。讀取後會先顯示活動預覽，使用者可逐筆勾選要匯入的活動，並在執行 Wealthfolio `checkImport` 前映射標的；只有通過驗證且未被判定為重複的活動才會匯入或下載。

Addon 不會保存原始檔、不會自動補入或轉出資金、不會自動建立帳戶或修改市場報價。相容 Wealthfolio 3.8.0 以上；匯入列的 `amount` 保留券商最終結算額（含費稅），主機驗證只在 amount 缺少時推導。去重會先使用 Wealthfolio 原生結果，再以帳戶、日期、活動類型、標的、幣別與經濟數值做補強比對，兼容缺少 amount 的舊資料及小數四捨五入差異；已有兩個明確最終金額但數值不同時不會視為重複。若主機無法讀取既有活動，介面會明確提示只採用原生去重。

中信 ESPP 新版 `consolidated.csv` 須含「日期、類型、提存別、股數、申購金額、標的」。依標的及公提／自提分開建立 FIFO 成本池，同日同類別的買入合併，以實際申購金額計算成本，忽略均價欄。「轉出」按其提存別承接 FIFO 成本，在轉出日期產生 `BUY`，股數沿用轉出股數，手續費為 0，扣除券商現金。來源「買入」只建立成本批次，不另外產生買入活動；不同提存別不互借股數或成本。完成各自 FIFO 分攤後，同日、同標的的公提／自提合併成一筆 BUY，股數與成本加總，單價以總成本除以總股數計算，備註保留兩者的成本來源。

請每次提供完整且不重複的 consolidated 歷史；addon 先計算整份資料，再套用預覽日期篩選。尚未入庫的股數與成本會顯示在轉換訊息，不產生活動；轉出超過可用股數或買入缺少實際申購金額時，整份 ESPP 轉換停止。FIFO 計算保留小數，輸出成本與單價至小數點後 8 位。3.8 主機以已存 `amount` 作為最終現金，不會以公式覆蓋券商結算額；舊版「買入日期、股數、均價、標的」仍沿用 BUY 匯入並扣款；先前已匯入的 BUY 不會自動改寫或刪除。

Schwab 再投資交易會保留券商的成交價與最終 Amount，不再改寫單價來迎合舊版主機重算；舊 TDA 股息描述中的括號代號會自動恢復，TD 移轉至 Schwab 的成對現金與持倉內部轉帳則會略過。對帳基準中的 9 碼債券會略過本金買賣，只將可由同一份 CSV 計算出的到期折價收益轉成 `DEPOSIT`，以對齊既有帳戶的逐日現金結果。台股權證因代號可重複使用，也不會匯入。股息、稅款與選擇權會使用跨 asset/subtype 別名的經濟去重。

升級 Wealthfolio 前請先備份資料庫；3.8 首次啟動可能遷移舊交易，請先處理 Activities → Needs review，再在所有同步裝置完成升級後新增或修改活動。
