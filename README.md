# Wealthfolio 對帳單匯入

將富邦證券複委託、永豐證券、Charles Schwab、基富通與中信 ESPP 的 CSV 對帳單轉換為 Wealthfolio 活動，先預覽並驗證，再直接匯入或下載標準 CSV。

## 開發

```bash
pnpm install
pnpm type-check
pnpm test
pnpm build
pnpm dev:server
```

每次匯入只處理一個 CSV，並由使用者選擇目的帳戶。讀取後會先顯示活動預覽，使用者可逐筆勾選要匯入的活動，並在執行 Wealthfolio `checkImport` 前映射標的；只有通過驗證且未被判定為重複的活動才會匯入或下載。台灣券商欄位中的「手續費」會寫入 `fee`，「交易稅」會寫入 `tax`；富邦的「印花稅」也會歸入 `tax`，不再與費用合併。

Addon 不會保存原始檔、不會自動補入或轉出資金、不會自動建立帳戶或修改市場報價。相容 Wealthfolio 3.8.0 以上；匯入列的 `amount` 保留券商最終結算額（含費稅），買賣缺少原始價格、數量或最終金額時停止匯入，不接受主機推算的金額補值。去重會先使用 Wealthfolio 原生結果，再以帳戶、日期、活動類型、標的、幣別與經濟數值做補強比對，兼容缺少 amount 的舊資料及小數四捨五入差異；已有兩個明確最終金額但數值不同時不會視為重複。若主機無法讀取既有活動，介面會明確提示只採用原生去重。

Schwab 再投資交易會保留券商的成交價與最終 Amount，不再改寫單價來迎合舊版主機重算；舊 TDA 股息描述中的括號代號會自動恢復，TD 移轉至 Schwab 的成對現金與持倉內部轉帳則會略過。債券每100美元面額轉為一單位，保留原始每百元報價與最終收付金額；到期配對紀錄缺原始價格時，僅符合已授權的按面額贖回特例才可匯入。拆股須有原始 Split Ratio，amount 儲存比例而非現金總價；無原始比例時，僅在來源股數歷史可精確還原正整數比例時推算；無法核對則報錯。台股權證因代號可重複使用，也不會匯入。股息、稅款與選擇權會使用跨 asset/subtype 別名的經濟去重。

升級 Wealthfolio 前請先備份資料庫；3.8 首次啟動可能遷移舊交易，請先處理 Activities → Needs review，再在所有同步裝置完成升級後新增或修改活動。

中信 ESPP 每筆買入必須同時提供原始「股數、均價、申購金額、標的」及「日期」（或舊版「買入日期」）。股數、均價與申購金額各自保留來源數值，不互相推算、不合併同日交易、不額外四捨五入。來源含類型欄時只接受買入，轉出略過；缺少原始價格或金額時整份停止匯入。只有「日期、類型、股數、均價、標的」的 consolidated.csv 可以辨識，但因缺申購金額而不能匯入。

所有機構的買賣價格、數量與總價各自來自原始欄位，不互相推算、不合併重算。富邦採價格／股數／應收付，永豐採成交價／數量／應付或應收金額，Schwab 採 Price／Quantity／Amount，基富通採淨值／單位數／總金額。Schwab 股息不再補入價格與數量 1；沒有價格或股數的現金活動保持空白，但須提供原始金額。

Schwab 支援 ADR Mgmt Fee → FEE/ADR_FEE、Foreign Tax Paid → TAX/WITHHOLDING。選擇權開平倉採主機 POSITION_OPEN／POSITION_CLOSE，到期採 ADJUSTMENT/OPTION_EXPIRY。指派使用同一平倉機制並保留 Assigned 備註，須能唯一配對來源股票交割；不另行推算股票交易。日期採 Date 欄位前面的日期，忽略 as of 後的日期。

經使用者授權，拆股可由完整CSV的拆股前股數及增配股數推算比例。同標的連續增配紀錄（最多7天內、無中間買賣或未知轉倉）可合併整股與零股入帳，使用最後生效日；比例必須精確為正整數，不做近似四捨五入。預覽列出原始列、股數、價格與推算依據。NVDA：0.7096 + 6 + 0.3864 = 7.096，推算10:1。SPLIT 的 amount 是主機拆股比例，不是現金總價；買賣價格與總價仍不可互相推算。

已授權債券到期按面額贖回特例：同代號、同來源日期的 Full Redemption／Full Redemption Adj 必須唯一配對，描述須確認到期，負沖銷面額的絕對值必須精確等於正本金，兩列費用皆為零且無額外數量／金額。缺原始價格時採每百元面額100，警告與備註明示非CSV原始價格；總價仍直接使用原始本金，不由價格推算。其他缺價情況繼續報錯。

中信目前六欄 consolidated.csv「日期、類型、股數、均價、申購金額、標的」已支援，不需要提存別。每筆買入直接保留原始股數、均價及申購金額；即使股數乘均價不等於申購金額，也不改寫任一數值。
